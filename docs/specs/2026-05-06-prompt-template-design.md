# 规范模板 — 设计规格文档

## 1. 产品定位

帮助用户在新建提示词时从经过实践验证的"五要素"骨架开始，而不是从空白文本框开始。降低写出好提示词的门槛。

## 2. 核心功能

### 2.1 模板插入

- 新建提示词弹窗的"内容"字段标签右侧加一个 `📋 使用模板` 按钮（与已有的"+ 添加变量"按钮风格一致）
- 点击后将"五要素"骨架文本写入内容输入框
- 仅在内容字段为空时启用按钮（防止误覆盖用户已写的内容）
- 编辑提示词时不显示按钮（防止覆盖已有内容）

### 2.2 模板内容

固定内置一个模板，第一版不允许用户自定义：

```markdown
## 角色
你是一位 [...]

## 任务
请帮我 [...]

## 输出格式
- [...]
- [...]

## 约束
- 不要 [...]
- 必须 [...]

## 示例
输入：[...]
输出：[...]
```

设计原则：每个段落留有清晰的占位符（`[...]`），用户一目了然该填什么。

## 3. 数据模型

无新增数据库字段。模板作为前端常量。

## 4. 技术架构

新增前端常量文件 `src/lib/templates.ts`：

```ts
export const PROMPT_TEMPLATE = `...`;
```

修改 `src/components/PromptForm.tsx`：
- 在内容 textarea 上方添加按钮
- 按钮 onClick → `setContent(PROMPT_TEMPLATE)`
- 按钮 disabled 条件：`content.trim() !== ""` 或 `initial !== undefined`（编辑模式）

## 5. 界面设计

**位置**：内容 textarea 标签的右侧，跟"+ 添加变量"风格一致。建议布局：标签和"📋 使用模板"按钮同一行，textarea 上方。

**样式**：链接样式按钮（`text-xs text-secondary hover:text-orange-300`），跟当前的"+ 添加变量"风格统一

**文案**：`📋 使用模板`

## 6. 不做的事情（第一版）

- 不做用户自定义模板（第一版只用内置一个）
- 不做多个模板可选（只有一个"五要素"模板）
- 不做"应用部分模板"（要么全插，要么不插）
- 不在提示词内容里强制要求保留这五个段落（用户可以删改）

## 7. 工作量估算

约 0.5 小时。无后端改动，无依赖。
